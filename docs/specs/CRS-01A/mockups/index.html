Decisions that shape this design

  1. System and academic administrators edit; coordinators view.
  2. Title corrections update live old-term views. Captured publication and claim labels stay unchanged.
  3. Recorded use locks code, credits, type, ownership, semester and room requirements.
  4. Unresolved teaching use blocks deactivation. No deletion.
  5. Academic credits stay separate from assigned workload; classification is explicit.
  6. Preserve imported facts, suffixes and unknown values; refuse new collisions.
