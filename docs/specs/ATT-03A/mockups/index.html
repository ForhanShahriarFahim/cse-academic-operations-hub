3 · Reopen with a reason

Reopen, void and restore use the same labelled dialog. The reason is required and stays in place if the server refuses the request.

Reopen 16 January for correction?

The submitted roll-call is kept in History. The session becomes editable and must be submitted again.

3–300 characters. Describe the correction; do not include marks, grades or contact details.

6 · Lock all submitted (reviewer)

A group-level action. The confirmation names exactly what will and will not change.

Lock 7 submitted sessions?

  • 7 submitted will be locked: 5 Midterm, 2 Final.
  • Not affected: 1 draft, 1 reopened, 3 already locked, 1 voided.

Up to 300 characters.

7 · Voided

Kept, read-only and excluded from summaries, the duplicate check and the Today card. A new session can be created for the same date and time.

Voided

Sunday 18 January 2027 · 9:30–11:00 AM · Midterm

Voided by Sample Teacher ST · 18 Jan, 12:30 PM

Reason: Class was rescheduled to 11:00; this roll-call was opened for the wrong slot.

Restore is offered only to a reviewer. It returns the session to Reopened and is refused if an active session already uses the same date and time.
