What this slice does.

Start each cohort from what the previous term offered at the same stream and semester, see carried / added / dropped before saving, then adjust one offering at a time. Teachers, class groups and timetable stay in the next slice.

Decisions to approve

  1. D-1 Editors. System and academic administrators; coordinators view only.
  2. D-2 Terms. Draft and active terms are editable; completed terms are read-only.
  3. D-3 Clone basis. Match by stream and curriculum semester, not by cohort.
  4. D-4 Comparison. Carried, added, dropped, changed — courses and status only; teachers arrive with class groups.
  5. D-5 Lifecycle. Cancel and restore with a reason; remove only in a draft term; offerings already in a class group are left alone.
  6. D-6 No database change. Reasons and history go to the existing change log.
  7. D-7 Out-of-semester courses. Allowed with a visible note and an explicit tick.
